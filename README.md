# Xtraordinary Journeys

A polished, one-page website for **Debbie**, an independent travel specialist offering tailor-made luxury journeys, travel arrangements and booking support. No paid software, build process, analytics, form service or backend is required.

## Publishing on GitHub Pages (free)

1. Open repository **Settings → Pages**.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select branch **main**, folder **/(root)** and click **Save**.
4. When GitHub finishes deploying, visit https://benbarraclough.github.io/xtraordinary_journeys/.

Until Pages is enabled, the live URL may show a 404, even though the website files are committed.

## Before sharing publicly

- **Business name confirmed:** Xtraordinary Journeys.
- **Add Mum's logo.** The website currently uses a tasteful text wordmark. Replace the two temporary wordmark blocks in index.html with the supplied logo; update assets/favicon.svg if appropriate.
- **Confirm the best contact email and Instagram account.** Replace the temporary contact panel in the enquiry section with the actual email/Instagram links. No invented contact addresses have been published.
- **Debbie is introduced by name.** Before launch, review her first-person biography with her and, if desired, add a portrait, specialist destinations and further career detail.
- **Business scope confirmed:** Debbie researches, advises, designs itineraries, liaises with resorts and travel providers, finds suitable deals/options, arranges and books travel. **Before accepting bookings**, confirm whether she operates as agent for a principal ATOL holder, an accredited body member, or another lawful model, and who acts as organiser for any package travel. Publish accurate booking/financial-protection details and any applicable terms once confirmed. The site does **not** claim unverified ATOL, ABTA or other membership. UK guidance: https://www.caa.co.uk/atol-protection/atol-requirements-for-the-travel-industry/do-i-need-an-atol/ and https://www.gov.uk/government/publications/package-holidays-complying-with-regulations-guidance-for-businesses.
- **Review and approve the copy and imagery** before promoting to prospective customers.
