# Xtraordinary Journeys

A polished, one-page website for an independent luxury travel consultancy. No paid software, build process, analytics, form service or backend is required.

## Publishing on GitHub Pages (free)

1. Open repository **Settings → Pages**.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select branch **main**, folder **/(root)** and click **Save**.
4. When GitHub finishes deploying, visit https://benbarraclough.github.io/xtraordinary_journeys/.

Until Pages is enabled, the live URL may show a 404, even though the website files are committed.

## Before sharing publicly

- **Confirm the business name.** The website says **Xtraordinary Journeys**, matching the repository spelling, but the original request also used "Xtaordinary".
- **Add Mum's logo.** The website currently uses a tasteful text wordmark. Replace the two temporary wordmark blocks in index.html with the supplied logo; update assets/favicon.svg if appropriate.
- **Confirm the best contact email and Instagram account.** Replace the temporary contact panel in the enquiry section with the actual email/Instagram links. No invented contact addresses have been published.
- **Personalise the biography.** Add her name, actual experience, special interests and a portrait if she would like.
- **Clarify whether she is consulting, arranging bookings or selling travel.** Verify any relevant disclosures, supplier affiliations, fees, financial protection and regulatory wording before describing these publicly. We have not claimed any unverified ATOL or ABTA membership.
- **Review and approve the copy and imagery** before promoting to prospective customers.

## Files

- index.html: page content and SEO metadata
- assets/styles.css: colour, typography, desktop and mobile styling
- assets/site.js: accessible mobile navigation and copyright year
- assets/favicon.svg: temporary icon
- .nojekyll: serve files without an extra processing step
